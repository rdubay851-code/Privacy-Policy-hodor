Before publishing:
1. Confirm the descriptions of data processing match the features actually enabled and the data your bot stores.
2. Publish index.html on a public HTTPS static host (for example GitHub Pages).
3. Paste the resulting public URL into Discord Developer Portal > your application > General Information > Privacy Policy URL.
4. Review and update the effective date and policy whenever practices change.
